Welcome to **Obsidian** — a dark, elegant starter theme for BlogBuilder.

This theme demonstrates how a site can look beautiful out of the box without any custom design work. It's built on:

- A carefully crafted dark color palette
- Elegant typography using Inter + Georgia
- Subtle animations and hover states
- Fully responsive layout

### Features

1. **Dark-first design** — easy on the eyes, especially at night
2. **Builder-native** — every element has a `data-builder-id` so you can edit it visually
3. **No build step** — plain HTML/CSS, deploy anywhere
4. **Git-backed** — your entire site lives in a repository

### Getting started

Clone this repo, run `npm install && npm start`, and you'll have a fully functional site editor at `http://localhost:4321`.

```bash
git clone https://github.com/yourusername/your-site.git
cd your-site
npm install
npm start
```
